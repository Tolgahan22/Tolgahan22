## Vampir Köylü

Altı köylüden biri vampir. İzleyicilerin olay yerini seçsin, köylüleri sorgulasın ve gece çökmeden şüpheliyi oylasın. Oyunu kendi yayınında ücretsiz kullanabilir ya da önce tarayıcıda bir tur deneyebilirsin.
